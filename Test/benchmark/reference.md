# pyg-lib 性能测试结果

表中为各用例计时调用的平均耗时；预热/计时表示调用次数。geometry、spline 为本次日志，使用 CUDA；subgraph 沿用原日志，使用 CPU。dtype 在 graclus_cluster 中指边权，在 random_walk/subgraph 中指图索引，其余指浮点输入。

输入在计时前生成，并在同一用例的预热和计时中复用。`torch.rand` 的浮点值位于 `[0,1)`；下文的 `torch.randint`、`torch.randperm`、随机坐标和随机权重均未固定种子，也未写入旧日志，因此历史运行的随机矩阵不能逐元素还原。

## 使用说明

1. 在已编译并能 `import pyg_lib` 的 Python 环境中运行。以下命令均从 pyg-lib 源码根目录执行；`benchmark/ops/geometry.py`、`benchmark/ops/spline.py`、`benchmark/ops/subgraph.py` 是本次修改的测试脚本。若源码目录中尚无这些脚本，先将对应的同名文件复制到 `benchmark/ops/`。
2. subgraph 使用 CPU。`--warmup 20 --iter 100` 表示每项先预热 20 次，再计时 100 次。表格中的用例编号从 0 开始。
3. 命令将结果同时显示在终端并写入 pyg-lib 源码根目录下的 `results/`。日志中每行末尾的 `ms` 是该用例的单次平均耗时；遇到 `UNSUPPORTED` 或非零退出码时，该用例没有有效性能结果。

## 运行命令

```bash
mkdir -p results
set -o pipefail
python -u benchmark/ops/geometry_cuda.py --device cuda --warmup 20 --iter 100 2>&1 | tee results/pyg_geometry.txt

python -u benchmark/ops/spline_cuda.py --device cuda --warmup 20 --iter 100 2>&1 | tee results/pyg_spline.log

python -u benchmark/ops/subgraph.py --device cpu --warmup 20 --iter 100 2>&1 | tee results/pyg_subgraph_cpu.log
```
